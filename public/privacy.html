Privacy Policy

Last updated: 2026

BotFusion provides tools and APIs for Telegram bot developers. This Privacy Policy explains what data we collect and how it is used.

Information We Collect

  • Email address used for account registration
  • Telegram User ID for account verification
  • Bot usernames and bot tokens (stored securely)
  • Telegram user IDs imported or synced via AutoUp API
  • API usage logs and request data
  • Link click analytics and usage statistics
  • Images, text, or data sent to APIs for processing (QR, anomaly detection, moderation, etc.)

How We Use Information

  • To provide dashboard and API services
  • To synchronize Telegram users with your bots
  • To analyze behavior for anomaly detection
  • To generate analytics such as link tracking
  • To improve system performance and prevent abuse

Bot Tokens & Security

Bot tokens are stored securely and are never displayed again after being added. Users are responsible for keeping their account password secure.

No Ads on Users Bot

We will not use your bot token for advertisement purposes.

Data Sharing

We do not sell or share your personal data. Data is processed only to provide the BotFusion services.

Third-Party Services

We may use third-party hosting providers and infrastructure services to operate the platform.

Data Retention

We do not store unnecessary data longer than required for system functionality.

User Responsibility

Users are responsible for how they use their bots and the data they process using BotFusion. BotFusion does not bypass Telegram policies; users must still follow Telegram rules.

Changes

We may update this Privacy Policy at any time.
